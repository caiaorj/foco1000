# Rumo aos 1000

Recriar o projeto Foco Mil Reais com o frontend completo: uma plataforma de accountability para membros da comunidade acompanharem o progresso rumo aos primeiros R$ 1.000 faturados.

Inclui todas as telas e componentes:
- Painel "Meu Negócio" (cadastro do projeto, meta e faturamento acumulado rumo aos R$ 1.000)
- Feed da comunidade com postagens e check-ins diários (foto, texto explicativo e valor faturado)
- Modal de novo check-in
- Ranking dos participantes da comunidade
- Perfil do participante com histórico
- Cartão de compartilhamento de progresso para redes sociais (ShareCard)
- Banner de avisos e atividades

Manter tudo funcionando 100% no frontend com dados mockados/armazenamento local no navegador, sem ativar o Lovable Cloud, para permitir a posterior conexão com banco Supabase externo.
